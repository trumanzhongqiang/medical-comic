# 奈特解剖涂色书 · 使用说明

把《奈特解剖涂色书》（Netter's Anatomy Coloring Book）作为**解剖准确性参考**：器官位置、毗邻关系、形态比例以此为准。

## 版权红线

- 奈特（Frank H. Netter）插图版权归 Elsevier 所有。拥有纸书只获得阅读权，不获得复制、改编或公开传播权。
- **不能**扫描、描图、抠图，也不能把书页照片交给图像模型“重画一张不一样的”。生成结果和原图不完全一样，仍然可能是受保护画面的改编；版权比的是独创表达是否被沿用，不是像素是否相同。
- 可以学习的是解剖事实：位置、毗邻、比例、分层。合上书后，用本项目自己的漫画造型重画。
- 若最终画面还能认出是某一幅奈特图（同一剖切、同一构图、同一特征性概括），就不要用。
- 需要真实器官细节时，改用 `reference/anatomy/` 中已登记许可的 2D 图纸或 3D 离线渲染静帧。

## 建议放入的素材

- 用户可把书中相关页的**自己拍摄/扫描的照片**放入本子目录，按系统命名：
  - `digestive-pancreas.jpg`、`cardiovascular-artery.jpg` 等
- 仅作内部参考，不进入成片，不对外分发。

## 每期开工前

对照本目录中对应系统的参考图，核对 story.js 里器官的造型与位置关系（如：胰腺头颈体尾走向、胃后毗邻、血管剖面分层）。
