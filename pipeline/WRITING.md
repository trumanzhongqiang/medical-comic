# 文案写作：让观众装得下

观众说「听不懂」，绝大多数时候不是字不认识，而是**一句话里要同时处理的新东西太多**，或者上一句留下的概念还没落地，就被下一句拿去用了。字少不等于密度低——把连接词和解释删掉，字更少，密度反而更高。

这份文档是写旁白时的第一参考。为什么这么写，见 `RETRO.md`（第 2 期六轮返工）；怎么念、怎么配，见 `README.md`。

---

## 一、三种压缩，是听不懂的真正来源

| 病 | 长什么样 | 第 2 期实例 |
|---|---|---|
| **句法压缩** | 一句里塞两件以上的事，四个分句连着推 | 「它大约能活四个月，糖一天天黏上去，黏得越久越多，所以这个数是一段平均。」31 字 / 4 个分句 |
| **概念压缩** | 一个词先被反复使用，过五句才来解释它 | 「平均」在第 2、3、4、7、8 句连着用，第 13 句才讲红细胞凭什么能代表三个月 |
| **指代压缩** | 「一个……一个……」「这个数」「它」让观众回头找 | 「一个是拍一张照片，一个是把三个月平均下来」——哪个是哪个，得回上一句 |

三种病的成因是同一个：写的人脑子里已经有完整模型，就以为读者也有。**每写一句都要问：这一句里，观众要新接住几个东西？超过一个，就拆。**

## 二、六个手法

1. **一句只推进一件事，但这一件事要带理由。**
   不是「空腹只管抽血那一下」（电报），也不是「空腹血糖反映瞬时血糖水平同时受近期饮食影响」（论文）。而是「空腹正常，只说明没吃饭那一会儿血里的糖不高」。一件事 + 一个限定，五秒念完。

2. **术语就地垫半句同位语，不要另开一拍解释。**
   「另一个数叫糖化，就是血里的糖黏在红细胞上、黏了三个月，量出来是这个数。」——名字、机制、来源挤在同一口气里，观众不需要记住一个空名词等三句。
   反面：第 2 期先把「平均」用了五句，第 11 句才回头讲红细胞，中间全靠观众悬着。

3. **抽象名词解压成「谁做了什么」。**
   「平均就被抬上去」→「把这些数加起来一平均，糖化就上去了」。
   「这个数是一段平均」→「所以糖化看的不是哪一天，是这一段」。
   中文里最容易被抽象化的词：平均、情况、结果、过程、程度、状态、趋势。它们做主语的时候，观众找不到动作的执行者。

4. **指代换成名词，宁可多说四个字。**
   「一个是拍一张照片，一个是把三个月平均下来」→「空腹血糖像拍照片，只拍那一刻。糖化像把三个月加起来除一除。」
   一句里出现两个「一个」，就必须回头对号；换成名字，眼睛不用动。

5. **长短必须交错，长句后面跟一个短句落点。**
   全片句长标准差低于 5，听起来就是一条平线，十句之后注意力就掉了。每三五句给一句 6–12 字的短句（「问题其实在饭后。」「所以只看这一个数不够。」），像呼吸。

6. **先写主核，再写卫星。**
   主核就是这一期要观众带走的那一句，通常等于封面点题句（第 2 期：「空腹看那一刻，糖化看三个月」）。其余每一句都要能回答「我是在支撑主核的哪一半」；回答不出来的，删掉。
   写不出主核，说明这一期还没想清要讲什么——先别动笔。

## 三、结构模板

```
0  主核句（先写，写在纸上，全片为它服务）
1  开场：把她的困惑原样问出来（疑问句，不用比喻）
2  两个对象各自给名字，名字后面立刻垫半句大白话
3  知识点 A：现象 → 为什么 → 所以说明什么
4  知识点 B：同上，用「反过来也有」接住
5  怎么办：一个具体动作（查什么、怎么查、带给谁看）
6  回到主核：封面点题，说的是两个名字各代表什么
```

一期三个知识点，每个四到五句，全片 15–16 句、95–105 秒。要更短就删知识点，不删解释。

---

## 四、两处硬禁

- **不用要先建模型的比喻**：账本、记账、攒、打架、考试、积分。观众得先接受一本账，再往里填数，等于多背一层。
- **不为了短而删连接词**：因为、可是、也就是说、所以——这些词不是废话，是给大脑的减速带。删掉它们，句子像压缩饼干：每个字都认识，读三行太阳穴发紧。这正是「太精炼听不懂」的技术成因。

## 五、工序（一次约 30 分钟）

```bash
# 1 先手写：主核句 + 三个知识点（各一句「是什么/为什么/跟她什么关系」）
# 2 展开成 15–16 句，边写边念出声
python3 pipeline/lint_narration.py <slug>          # 硬伤必须清零，提示逐条判
node remotion/scripts/check_wrap.mjs <slug>        # 断行：不劈词、不掉三行
# 3 配音 → 重排 → 整轨转写核对（见 RETRO.md 第三节）
```

体检脚本查的是客观指标：单句 30 字以上或五个分句以上算硬伤（一口气装不下）、句长标准差低于 5 报节奏扁平、抽象名词做主语、术语首现没解释、多音字当动词用、同一期量词口径打架、被否掉的比喻。它查不出「这一句到底有没有用」——那一步仍然只能人念一遍。

## 六、第 2 期三处示范改写

| 原句 | 问题 | 改写 |
|---|---|---|
| 一个是拍一张照片，一个是把三个月平均下来，对不上很正常。 | 两个「一个」要回头对号；「平均」抽象 | 空腹血糖像拍照片，只拍那一刻。糖化像把三个月加起来再除一除。所以对不上很正常。 |
| 三个月里一顿又一顿都这么冲，平均就被抬上去，问题其实在饭后。 | 抽象名词当主语，「被」后面没有执行者 | 三个月里，一顿又一顿都这么高。把这些数加起来一平均，糖化就上去了。问题其实在饭后。 |
| 它大约能活四个月，糖一天天黏上去，黏得越久越多，所以这个数是一段平均。 | 31 字 4 个分句，一口气装不下 | 红细胞大约能活四个月。糖一天天黏上去，黏得越久，黏得越多。所以糖化看的不是哪一天，是这一段。 |

改完每句只推进一步，句子反而更好念——不是因为变短，是因为**每一句只让人接住一个新东西**。
